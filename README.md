# Pocket AI v0.2.1 — MLC/WebLLM + HTTPS

This build keeps the MLC/WebLLM architecture from v0.2.0 and adds a local HTTPS development server. The previous v0.2.0 build correctly refused to initialize because `http://10.0.0.103:5171` was not a secure context.

Safari 26 supports WebGPU on iPhone and macOS, but WebGPU requires a secure context. A LAN HTTP address such as `http://10.0.0.103:5173` does not qualify; `https://10.0.0.103:5173` does.

## Run

On the Mac:

```bash
npm install
npm run dev
```

Vite will now start HTTPS automatically and should report an address similar to:

```text
https://10.0.0.103:5173/
```

The certificate generated by `@vitejs/plugin-basic-ssl` is intentionally untrusted for development. Vite's plugin documentation says you can proceed through the browser warning; for a fully trusted local certificate, use mkcert instead.

### Mac test

Open the HTTPS address on the Mac. If Safari shows a certificate warning, proceed to the site. Then press **Load Local AI**.

The diagnostics should say:

```text
Connection: HTTPS / secure
WebGPU API: yes
GPU adapter: yes
```

### iPhone test

On the iPhone, open:

```text
https://10.0.0.103:5173
```

If Safari presents the self-signed certificate warning, proceed to the site. If Safari refuses to proceed or does not establish a secure context, use the trusted-certificate route below.

### Recommended trusted HTTPS route: mkcert

Install mkcert on the Mac, then create a certificate for the Mac's LAN address:

```bash
mkcert -install
mkcert 10.0.0.103 localhost 127.0.0.1
```

Configure Vite's `server.https` with the generated certificate and key. For the iPhone, install the mkcert root CA and enable full trust under Settings > General > About > Certificate Trust Settings. The mkcert documentation describes this iOS trust process.

## What changed from v0.2.0

- Added automatic local HTTPS development server.
- Certificate includes `10.0.0.103`, `localhost`, and `127.0.0.1`.
- Kept real WebGPU adapter detection.
- Kept MLC/WebLLM only; there is no ONNX/WASM fallback.
- Kept Qwen2.5-0.5B-Instruct Q4.
- Kept IndexedDB model caching.
